# Hiring workspace design

Staffing vendors submit resumes; hiring managers review contract candidates. The primary task is to move from an opening to a candidate decision while preserving tenant context.

Use the existing Zelosify logo and monochrome shell. Palette: canvas #f7f9fc, surface #ffffff, ink #172133, muted #617087, blue action #2859cc, green status #187856. Dark surfaces inherit the existing #111827 foundation. One system sans-serif family: 28px page titles, 16px section titles, 14px operational copy.

Desktop: compact left navigation, tenant and role context, a wide openings table with search and status filters. Detail: a readable opening brief and requirements panel, followed by candidate files and decisions. Mobile: compact top navigation, stacked details and table rows, with no screen-size blocker.

The distinctive element is the requisition brief: a quiet blue title band grouping role, location and contract details. Status is written explicitly alongside color. Avoid decorative KPI cards and unrelated payments content.

Reviewed against the assignment: retain brand and themes, replace the desktop-only blocker and empty manager navigation for these routes, and organize the experience around openings and files rather than generic analytics.
